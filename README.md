## 휴가 계산기 화면 구성 (가독성 정리)

- **입력은 한 카드("휴가 입력")**: 위쪽 스위치로 **실제 휴가 / 휴가 계획**을 고릅니다. 계획을 고르면 "주말출근 제외" 체크가 사라지고 "계획 저장" 버튼이 됩니다.
- **복무 정보 한 배너**: 복무일 숫자(전체·현재·남은·실제 남은 출근일·다음 휴가·예정 휴가일) + 진급 일정 + 입대일·전역일 수정이 한 카드 안에 있고, 평소엔 접혀 "실제 남은 출근일 43일 · 상병 진급 D-12" 요약만 보입니다. **휴가 사용 현황 · 이 달 기록 · 이 달 계획도 접혀** 있고 접힌 줄에 "한도 초과"·"계획 N건"·"3건" 같은 요약이 보입니다. 저장·삭제 직후에는 기록·계획 목록이 자동으로 펼쳐집니다.
- **달력 달 이동(‹ ›)은 페이지 새로고침 없이** 바로 바뀝니다(스크롤·펼친 칸 상태 유지). 아래 "○월 기록·계획" 패널은 처음 연 달 기준입니다.
- **달력의 휴가 종류별 색**: 위로 파랑 · 정기 남보라 · 포상 초록 · 공가 주황 · 연가 청록 · 외출 회색 · 면회 분홍. 휴가 계획은 같은 색의 점선 칩. 달력 아래에 색 범례가 있습니다.
- **입대일·전역일 수정**은 이름 아래 날짜 줄 오른쪽의 작은 **"수정"** 버튼을 누르면 그 자리에서 열립니다(복무 정보 안에서는 뺌).
- 화면 순서: 전역 진행률 → 복무 정보(접힘) → **○월 기록·계획(한 패널, 접힘)** → 달력 → 휴가 입력 → (같은 반 휴가 일정) → **휴가 사용 현황(맨 아래, 접힘)**

## 출근 명단 정렬 (높은 기수 순)

- 근무일 화면의 **확정 명단 · 동별 출근 인원 · 계급별 출근 인원**(복사 글 포함)은 **높은 기수(작은 숫자)부터** 나열합니다. 동별은 한 줄 안에서 높은 기수 → 계급 → 가나다 순, 계급별은 계급(병장→이병)으로 묶은 뒤 그 안에서 높은 기수 순입니다. 기수가 없는 사람은 맨 뒤.
- 휴가 계산기 "복무 정보" 접힌 줄에서 "진급 완료" 글자를 뺐습니다(진급이 남았을 때만 "상병 진급 D-12" 표시).

## 하단 메뉴 · 라인업 불참 목록

- **하단 메뉴는 "주말출근 투표" / "휴가 계산기" 두 개뿐**입니다. 라인업은 홈의 "라인업 파일 확인" 줄로 들어갑니다(라인업 화면에서는 "주말출근 투표" 탭이 선택된 상태로 보임).
- 라인업의 **불참 목록은 높은 기수(작은 숫자)부터 한 사람당 한 줄**: `기수  계급 이름  날짜  [사유 배지]` (사유 배지에는 종류·상세, "라인업 불참"은 직접 쓴 사유만). 기수가 없으면 맨 아래. 불참이 많아져도 길어지지 않게 촘촘하게 만들었습니다(삭제는 오른쪽 ✕).

## 홈 화면 우선순위 구성

위에서 아래로 중요한 순서입니다.
1. **1순위**: **휴가·불참 입력**(가장 큰 파란 버튼) → **1차 명단**(내일 출근자 중 높은 기수 9명 + 예비 2명) → **주말출근 투표**(마감 카운트다운 한 줄 + 근무일 목록과 내 응답)
2. **2순위**: **라인업 파일 확인**(한 줄, 내일 출근·불참 인원 수 표시)
3. 맨 아래 작은 글씨: 출근 기록·통계, 비밀번호 변경, 로그아웃(관리자는 "관리자 메뉴")

## 인원 등록 시 기수·반 · 같은 반 휴가 겹침 미리보기

- **인원 한 명 추가**: 이름 → 계급·기수·반 → 운전병 순서로 한 번에 입력합니다(반을 진료반으로 하면 진료반 여부도 켜짐). 진료반 체크박스는 반 선택으로 합쳤습니다.
- **일괄 등록**: 열이 `이름, 초기비밀번호, 진료반 여부, 관리자 여부, 계급, 기수, 반` 로 늘었습니다(기수·반은 비워도 됨, 반은 "훈련"처럼 "반"을 빼고 써도 인식, "866기"도 인식).
- **휴가 계산기 → 휴가 입력**: 휴가 종류에서 **날짜를 고르는 즉시** 같은 반 사람과 겹치는지 미리 보여 줍니다("⚠️ 훈련반 1명과 휴가가 겹칩니다: 병장 홍길동 11.10~11.12" / "✓ 겹치는 사람 없음"). 입력 카드 아래 접힌 **"○○반 휴가 일정"** 에서 같은 반 전체 휴가·희망 일정을 미리 볼 수 있습니다. 반이 지정되어 있어야 보입니다.

## 라인업: 신규 불참·다시 출근 (직전 평일 기준)

- **신규 불참**은 "전날"이 아니라 **직전 평일**(주말·공휴일을 건너뛴 바로 앞 근무 안 하는 날)과 비교합니다. 월요일 라인업은 금요일과 비교하므로, **토·일부터 불참이 시작되어 월요일까지 이어지는 사람도 "신규"** 로 보입니다(금요일에도 불참이던 사람은 신규가 아님). 금요일이 공휴일이면 목요일, 연휴면 연휴 직전 평일과 비교합니다. 화~금요일은 그대로 전날과 비교하고, 화면에는 "새로 불참 N명 (주말 전엔 출근)" 또는 "(전날은 출근)"처럼 기준이 나옵니다.
- **다시 출근**: **쉬는 날(토·일·공휴일) 동안 불참이었다가 이 날 출근하는 사람** 이름을 불참 카드 **맨 아래에 작게**(기수 순) 적습니다. 예) 월요일 라인업 → 토·일에 불참(외박·휴가 등)이었다가 월요일에 출근하는 사람. **금요일에만 불참이던 사람은 나오지 않습니다.** 쉬는 날이 끼지 않은 화~금요일은 전날 불참이던 사람입니다. 화면에는 "다시 출근 2명 (주말 불참) · 이름…"으로 나오고, 복사 글에도 "■ 다시 출근" 줄로 들어갑니다. 해당자가 없으면 줄이 없습니다.

## 운전 지정 ↔ 주말 출근 추첨 · 선탑 규칙 변경

- **운전이 지정된 운전병은 그날 동·진료실 추첨에서 빠집니다.** `/drive`에서 주말·공휴일에 운전을 지정하면, 그 사람은 **희망을 눌렀어도·차출 대상이어도** 동·진료실 추첨에 들어가지 않고 **"주말 운전" 자리**를 먼저 채웁니다(확정 명단에 "운전 지정" 꼬리표). 지정이 정원보다 적으면 남은 자리만 기존 규칙(운전 희망 → 운전병 랜덤)으로 뽑고, 지정이 없는 날은 기존과 똑같습니다. 투표 화면에서 그 사람에게는 "제외"로 보이고 미응답 목록에서도 빠집니다.
  - 추첨이 **이미 끝난 날**에 나중에 지정하면 확정 명단은 자동으로 바뀌지 않습니다(저장 안내에 경고 표시) → 관리자 "명단 수정"에서 맞추세요.
- **운전 달력에 운전병 휴가 표시**: 운전 지정 화면의 달력에 운전병들의 휴가가 주황색 "휴 이름"(계획은 주황 점선)으로 같이 보이고(운전은 진한 색 칸), 달력 아래 "운전병 휴가 일정" 목록에도 따로 나와서 서로 겹치지 않게 지정할 수 있습니다. 휴가가 겹치는 기간에 지정하면 저장 안내에 경고가 나옵니다. (휴가·계획만 표시, 교육 등 다른 불참은 표시하지 않음)
- **선탑 규칙**: 추첨이 끝나면 자동으로 **그날 운전병보다 기수가 같거나 높은 동·진료실 출근자 중 랜덤 1명**이 선탑이 됩니다(기수는 숫자가 작을수록 높음. 운전병이 여러 명이면 가장 높은 기수 기준, 운전병 본인·기수 미입력자 제외). 운전병이 없거나 기수가 없으면 자동으로 정하지 못하고 관리자 화면(근무일 화면 "선탑 뽑기", 명단 수정)에 이유가 표시됩니다. 관리자는 **[규칙대로 선탑 다시 뽑기]** 로 다시 뽑거나, 접힌 "직접 대상자를 골라 뽑기"로 예전처럼 골라 뽑을 수 있습니다. 변경 이력에 기준 운전병이 함께 기록됩니다.

## 주말출근 차출은 관리자가 버튼으로 (자동 추첨 없음)

- **자동으로 추첨하지 않습니다.** 투표가 마감돼도 사이트가 알아서 뽑지 않고(크론·접속 시 안전장치 모두 추첨은 하지 않음), 관리자가 **[주말출근 차출하기]** 를 눌러야 추첨됩니다. 투표를 안 해서 차출될 사람 중 실제로는 출근이 어려운 사람이 있을 수 있어, 관리자가 먼저 걸러내기 위한 단계입니다.
- **순서**(관리자, 근무일 화면): 마감 뒤 빨간 테두리 카드 "주말출근 차출하기"가 나타납니다.
  1. **후보 확인(스크리닝)**: 희망 확정 인원과 차출 예정 인원, 차출 후보(미응답 + 미희망)가 나옵니다. 출근이 어려운 사람을 체크해 **[이 날 추첨에서 빼기]** (그날 하루만, 아래 "제외" 목록에서 되돌릴 수 있음)
  2. **차출 실행**: **[주말출근 차출하기]** → 확인창 → 한 번만 실행. 동·진료실 추첨과 함께 **선탑도 자동으로 정해지고**(운전병보다 기수 같거나 높은 출근자 중 랜덤) 결과 안내에 표시됩니다. 뽑은 뒤 사정이 생기면 [명단 수정]에서 교체할 수 있습니다.
- 관리자 홈에는 마감 후 아직 차출하지 않은 날이 "주말출근 차출 대기 N일 + 날짜별 [차출하기]"로 뜹니다. 일반 인원에게는 그 날짜가 "마감 · 추첨 대기"로 보이고, 차출이 끝나면 결과가 보입니다. 투표 중에는 예전처럼 "추첨 미리보기"(저장 안 됨)만 있습니다.
- Vercel 크론(`/api/cron/draw`)은 그대로 두어도 됩니다. 계급 자동 진급·전역 처리만 하고, 응답에 차출 대기 날짜(`pending`)를 알려 줍니다. (자동 추첨 때문에 필요했던 설정은 더 이상 필요 없습니다)

## 홈 화면에 추가 버튼 (앱처럼 쓰기)

- 맨 위 **검정 바 오른쪽 끝**에 "＋ 홈 화면에 추가" 버튼이 있습니다(휴대폰에서만 보이고, 이미 홈 화면 앱으로 열었으면 숨김).
  - **안드로이드 크롬**: 누르면 설치 창이 바로 뜹니다. 설치 창이 안 뜨는 환경에서는 "⋮ 메뉴 → 앱 설치/홈 화면에 추가" 안내가 나옵니다(삼성 인터넷은 전용 안내).
  - **아이폰 사파리**: 웹사이트가 설치 창을 직접 띄울 수 없어서 "공유 버튼(□↑) → 홈 화면에 추가 → 추가" 3단계를 안내합니다.
  - **카카오톡 등 앱 안 브라우저**: 거기서는 추가가 안 되므로 "Safari/다른 브라우저로 열기" 안내와 [사이트 주소 복사] 버튼이 나옵니다. (단톡방 링크로 들어온 사람이 많아서 넣었습니다)
- 코드: `src/components/install-button.tsx`(버튼·안내), `src/components/global-bar.tsx`(검정 바), `src/app/manifest.ts`(앱 이름·아이콘·standalone).
